# SaltsNetUtils 0.1.0

This release uses SaltsBase 0.1.10, CMeta 0.1.10, SaltsUtils 0.1.8 and the
SaltsCNet revision pinned in [`.env.example`](../../.env.example). The CNet
SDK contains the HMAC-MD5, DES-CBC and AES-128-CFB128 operations used by
existing SNMPv3 deployments. SNMP and LDAP use the SaltsBase ASN.1 codec.
Email clients initialize CNet on the first thread that connects.

The Windows x64 (LLVM-MinGW and MSVC), Linux x64 and ARM64, and macOS ARM64
archives have native CTest and installed C11/C++17 consumer coverage. The
Android ARM64 and x64 archives are cross-built and installed. Android device
execution and iOS are outside this release's qualification.

Extract the archive matching your compiler and platform. Use the embedded
`dependencies/salts-cnet` directory for `SALTS_CNET_ROOT`, and set the other
SDK roots listed in [`.env.example`](../../.env.example). The
`saltsnet-sdk-manifest.json` in each archive records its source, compiler
profile and dependency checksums. Import the installed SDK through
`find_package(SaltsNet CONFIG REQUIRED)`.
